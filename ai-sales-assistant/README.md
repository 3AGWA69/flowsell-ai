# FlowSell AI — Sales Assistant Demo

A polished Arabic RTL demo for an AI sales assistant aimed at Egyptian social-commerce stores.

## Included
- Landing page focused on the value proposition
- Live conversational demo with quick replies
- Product catalog preview
- Sales dashboard with KPIs, conversations, and funnel
- Responsive RTL design
- No backend or paid API required for the demo

## Run locally

Requirements: Node.js 20+

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

The app is ready for Vercel deployment. In a real client deployment, connect the chat layer to WhatsApp Business/API, a product data store, and an LLM provider.
